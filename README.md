# Alice Voice Lab

Grok TTS `Eve` vs Gemini 3.1 Flash TTS `Laomedeia` — Japanese TTS comparison samples.

See **[index.html](./index.html)** via GitHub Pages for the full side-by-side listening experience (short samples, long-form drama, dialect probes, and Director's Notes demo).

---

## 概要（日本語）

2026年4月に数日差でリリースされた xAI の **Grok TTS**（voice: `Eve`）と Google の **Gemini 3.1 Flash TTS**（voice: `Laomedeia`, preview モデル）を、同じ話者ペルソナ（Alice・若めのナレーター像）のもとで横並びに検証した比較サイトです。

**[index.html](./index.html)** を GitHub Pages 経由で開くと、次の内容を同じ台詞・同じ条件で聴き比べられます。

- 10 シチュエーションの短文サンプル
- 方言・アクセント制御の probe（大阪弁・博多弁・京都弁・東北弁）
- Grok TTS 側の大阪弁読み上げと、Gemini 側への同一テキストの対照サンプル
- 約1分のナレーション（「街の朝」）と、Gemini の Director's Notes による演技指導版
- 感情タグを厚く重ねた約1分のドラマ（「二十年後の返事」）

検証条件、公式 pricing、商用利用可否、API 挙動の観察は index.html 側にまとめています。
